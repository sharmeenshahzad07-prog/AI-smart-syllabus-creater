How to RUN the project : 1. Start the Backend (API)
Open a terminal or cmd  in the backend folder and run:


.\venv\Scripts\python.exe -m uvicorn main:app --port 8000 --reload
2. Start the Frontend (UI)
Open a second terminal in the frontend folder and run:


npm run dev
3. Open the App
Once both are running, go to http://localhost:5173 in your browser.
